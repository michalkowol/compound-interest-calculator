# Compound Interest Calculator

A compound interest calculator for IKE, a partner's IKE, IKZE and a brokerage account, with Belka tax, IKZE flat tax, inflation and contribution limits. Available in Polish and English.

Live version: https://michalkowol.github.io/compound-interest-calculator/

To run it locally, open `index.html` in a browser. No install or build step needed (Alpine.js is loaded from a CDN).
